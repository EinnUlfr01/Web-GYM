# Cách dùng với Codex App

1. Mở repository GymFit trong Codex App.
2. Chép 4 file của gói này vào thư mục gốc repository.
3. Mở một task/chat mới trong Codex App.
4. Dán toàn bộ nội dung file `PROMPT_OUTSIDE_CODEX_APP.md`.
5. Cho Codex chạy trong repository hiện tại.
6. Không cần chạy CLI hoặc PowerShell.

Các file:

```text
README_TASK008_PLAN.md
PROMPT_00_DISCOVERY.md
PROMPT_01_IMPLEMENTATION.md
PROMPT_OUTSIDE_CODEX_APP.md
```
